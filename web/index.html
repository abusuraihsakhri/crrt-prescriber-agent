CRRT Effluent Dose & Fluid Balance

Local, browser-based arithmetic worksheet for continuous renal replacement therapy. Enter measured effluent and fluid volumes for the same observation interval.

Educational use only — not a prescribing system. The calculation does not validate anticoagulation, membrane clearance, downtime, filtration fraction, electrolyte management or patient-specific clinical suitability. A qualified clinical team must interpret results.

Measurements

Delivered effluent

Example values are prefilled. Use actual delivered effluent, not the nominal pump setting.

Fluid balance over the same period

Use net patient removal, not total effluent, to avoid double-counting replacement/dialysate flows.

Calculated results

Values are derived entirely on this device; no API calls, cookies or storage are used.

Observed effluent dose

—

Enter measurements and select Calculate.

Reference: KDIGO 2012 recommends a delivered CRRT effluent volume of 20–25 mL/kg/hour for adults with AKI. Observed effluent dose is only a proxy for delivered clearance.

Net fluid balance

—

Net balance = intake − non-CRRT output − net patient ultrafiltration. Positive results indicate net gain.

Reference: KDIGO AKI guideline summary, Part 2. No personal identifiers should be entered. Calculations are independent of the repository's Python APIs, which require a separate server.
